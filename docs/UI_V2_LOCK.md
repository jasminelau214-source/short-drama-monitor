# JSM V2 前端功能锁定说明

> 本文档用于锁定 V2 前端信息架构、页面职责与交互规则。后续实现不得随意改变已经确认的页面职责；新增能力优先作为二级能力或未来版本预留。

## 1. 一级导航

1. 市场总览
2. 今日榜单分析
3. 历史趋势分析
4. 题材 / 剧目研究
5. 系统设置（仅管理员可访问）

### 二级能力
- 历史剧目库：属于「历史趋势分析」的二级入口，不作为一级导航。
- 单剧详情：全系统统一实体页，不作为一级导航。任何剧目点击均进入同一 drama_id 的详情档案。

## 1.1 数据源呈现规则（2026-09-22 补充锁定）

- 前端业务分析不得只使用 App 榜单数据；所有**通过完整性与来源语义校验**的 Official Web 观察数据，也应进入市场总览、今日榜单观察、历史趋势、题材结构与单剧生命周期等分析。
- App 与 Official Web 可以共同进入“综合市场观察”，但每条记录必须保留来源标识，可用“应用榜单”“官方网页”等中文标签展示；不得把不同来源的榜位直接当作同一榜单比较。
- 当最新有效数据来自 Official Web 时，前端“最新市场数据日期”应更新到该日期，不得因为 App 采集停在较早日期而让整体前端长期停留在旧日期。
- Official Web 参与趋势/分析 ≠ 自动升级为 App 新剧。Newness、自动 Research Eligibility、正式 App 榜单事实仍按核心业务契约处理。
- 历史或异常数据在业务前端只标注日期、平台和异常状态；技术根因放在后台审计或项目对话中。

## 2. 市场总览

职责：情报驾驶舱 + 全系统导航，不做「简化版今日榜单」。

必须包含：
- 今日核心情报结论
- 关键情报信号：重点剧目 / 题材机会 / 异常或新信号
- 今日研究推荐
- 快速进入：今日榜单 / 历史趋势 / 题材研究 / 历史剧目库
- 极轻量系统状态

不应重复展示完整榜单、完整题材结构、完整平台表现或大型趋势图。

## 3. 今日榜单分析

职责：回答「今天具体发生了什么」。

锁定能力：
- AI 今日摘要
- 今日剧目 / 今日新剧 / 继续在榜 / 女频 / 男频，全部可点击筛选
- 完整榜单
- 排名变化：↑N / ↓N / →0 / NEW
- 单剧排名趋势 sparkline
- 今日重点剧目
- 当日题材结构
- 今日新剧列表
- 平台表现
- 近 7 个真实采集日趋势

## 4. 历史趋势分析

职责分为两层：

### A. 数据分析
回答「市场发生了什么变化」。
- 时间范围 / 男女频 / 题材 / 平台筛选
- AI 趋势结论
- 核心主图：题材占比趋势变化（基于真实采集点，不补造日期）
- 题材上升 / 稳定 / 回落
- 单剧生命周期
- 男女频趋势对比
- 历史剧目库入口
- 关键数据卡仅作为辅助信息

### B. 创作导向
回答「这些变化对创作有什么启发」。
- 题材创作机会
- 高频内容元素（优先基于高位样本）
- 男女频写法差异
- 代表剧可借鉴点
- 长期机会 vs 短期爆点

明确删除：将累计/总体「剧目数量趋势」作为主图。数量信息仅可降级为辅助指标。

## 5. 题材 / 剧目研究

职责：回答「为什么这种内容有效、可借鉴什么」。

锁定能力：
- 题材 / 男女频 / 平台 / 剧名筛选
- 题材研究摘要
- 样本量、平台覆盖、历史最高排名、记录采集日等真实数据指标
- 高频人设 / 关系 / 核心设定 / 开局钩子 / 冲突 / 爽点 / 反转 / 情绪等内容维度（有数据才展示）
- 题材趋势洞察
- 代表剧横向比较
- 单剧研究档案：市场表现、内容定位、内容深研、商业钩子、本土化、同类对比、相关资源
- 不展示当前系统没有可靠来源的播放量、用户评分等虚构指标

## 6. 系统设置

管理员专用。当前 V2 应围绕已有能力组织：
- 系统运行概览 / health
- 采集与任务管理
- 自动分析与深研配置
- 剧目资料补全
- 剧目去重 / 合并
- 标签 / 题材词库
- 系统日志
- 数据备份与版本
- 账号与权限（当前 Basic Auth；RBAC 作为 V3+ 预留）
- 未来能力预留必须明确标记为未启用，不得伪装成已实现

## 7. 全局交互规则

- 任何剧名、海报、剧目卡、榜单整行均可点击进入统一单剧详情。
- KPI、题材、平台、男女频、排名变化、趋势点等可钻取数据应可点击进入对应明细。
- 图表必须服务于一个明确问题，并能下钻到证据或样本。
- 历史趋势只使用真实采集点，不补造缺失日期或排名。

## 8. V3 / V4 / V5 数据模型预留

当前 UI 不需要全部展示，但底层实体应避免后续重构：
- drama
- drama_alias
- ranking_snapshot
- content_analysis
- drama_assets (poster / still / trailer / video / ad / landing_page)
- source_evidence
- external_signal
- intelligence_signal
- research_report
- watchlist
- analysis_version

版本只代表产品阶段，不应拆成 V2/V3/V4 独立数据模型。
